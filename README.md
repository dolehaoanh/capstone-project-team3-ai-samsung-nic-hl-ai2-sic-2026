ENGLISH BELOW
The first release is a Vietnamese-first, local web application for research and decision support:

- **MVP universe:** VN30, with a documented extension path to liquid HOSE/HNX equities.
- **Forecasting:** leakage-safe technical, market/sector, fundamental, and macro features; calibrated tabular models and walk-forward backtesting. Numeric forecasts are not generated by an LLM.
- **Operation:** offline cached snapshots by default, with an optional online refresh mode when data providers are available.
- **Outputs:** ranked stocks, expected return/risk, confidence, evidence, timestamps, provenance, and benchmark comparisons. Recommendations require explicit confirmation and a risk profile.
- **Safety:** this is educational decision-support software, not a guarantee of profit or personalized financial advice.

## Local development

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m pytest -q
uvicorn vietnam_stock_forecasting.api:app --reload
```

Then open `http://127.0.0.1:8000/docs`.

To explicitly refresh a cached snapshot from a free Vietnamese-market provider:

```bash
python -m pip install -e ".[data]"
```

The provider is intentionally optional: tests and inference remain offline and reproducible by default. Use `fetch_vietnam_history(...)` from `vietnam_stock_forecasting.data`, validate the result, and persist it with `write_csv_snapshot(...)`. Keep the retrieved date, provider, query range, and symbol list with the submitted dataset.

The repository is organized for five concurrent workstreams: data ingestion, feature/leakage controls, modeling/evaluation, backend/UI, and integration/review. GitHub Projects, Issues, pull requests, CODEOWNERS, and Actions are the project-management system of record.
